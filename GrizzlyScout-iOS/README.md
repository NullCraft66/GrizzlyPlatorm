# GrizzlyScout iOS

Native SwiftUI port of the Android GrizzlyScout client. It keeps the Android client's drawer navigation and visual language while using the same active form, event, match, alliance plan, submission, and update API contract.

Open `GrizzlyScout-iOS.xcodeproj` in Xcode 27 or later, select an iPhone simulator/device, and run. Set the signing team in the target's Signing & Capabilities pane before installing on hardware. Configure the API host and scout name from Developer API Settings when the server is not at the Android default address.
